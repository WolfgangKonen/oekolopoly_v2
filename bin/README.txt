config.txt can be adjusted in the following way:

Features can be disabled/enabled with numbers 0 and 1.
Example:
use_preview: 0
-> disables feature preview mode

use_predict: 1
-> enables predict mode (AI prediction)

use_diagrams: 1
-> enables diagrams, i.e. the bar plots for each sector

`group` can be ignored (was previously used to send mails to different student groups).

`predict_usages` determines the amount of AI predictions that can be made per game.
Numbers above 5 allow arbitrary many usages.
